溶接の単位長さあたり入熱計算機

電圧、電流、溶接速度が一定の場合に、母材へ伝わる単位溶接長さあたりの熱エネルギーを計算します。 入力単位を選択し、指定された条件内で 1 つの値を計算します。

入力値

0 以上

0 以上

SI 単位への換算後に 0 より大きい値

0〜1 の比率

計算はこのブラウザー内で行います。1.2e-3 などの指数表記に対応しています。桁区切り文字は使わないでください。

計算結果

単位溶接長さあたりの入熱 H

—

値を入力し「計算する」を押してください。

公式

H = ηUI/v; 1 kJ/mm = 10⁶ J/m

適用条件

一定電圧・電流・溶接速度と、工法に適した熱効率を用います。η=1 では効率補正前の単位長さあたりアークエネルギーです。パルス波形や交流波形では、平均電圧×平均電流と瞬時電力の平均が異なる場合があり、この一定パラメータモデルは適しません。熱影響部温度、冷却速度、溶接施工の適格性判定は扱いません。

表示値は浮動小数点数による近似値です。設計安全率や、入力されていない誤差要因は計算しません。
